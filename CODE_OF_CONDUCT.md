# Contributing Guidelines

Use common sense before adding an Issue, committing or opening a Pull Request. 

## AI Guideline

You are free to use AI for Code Generation, Review etc. but the following rules should always be obeyed: 

- Do not offload review or understanding to other users or the AI. If you do not understand what the AI is doing just keep it for yourself - anybody else can do the same so there is no value in you submitting it.
- Generating Issues with a Wall of Text will make others not wanting to help you - so keep it short and to the point.
